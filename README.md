# To-Do-List-Project

## What is the project about?
To-Do list project where you can manage your daily tasks in a list.

## Features:
1) Add Tasks
2) View Tasks
3) Mark Tasks as Done
4) Remove Tasks

## Libraries:
os & json: Used it to save the to-do list in a .json file and load it each time the program runs so that I am able to save the list even after quitting the program.
This was the bonus point in the task
